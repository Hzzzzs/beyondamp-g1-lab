# 平地候选动作的运动学改进记录

这些结果来自 CPU 运动学审计，不代表强化学习收敛、接触力正确或双模拟器行走通过。验证片段也用于开发诊断，不能把它称为从未见过的最终测试集。

## 方法与取舍

- `anchor_v2`：人体高度推断单支撑，支撑段固定踝 XY；释放支撑后直接回到人体目标，存在突变。
- `smooth_v3`：支撑段之间用五次曲线连接 XY，使完整摆动两端速度与加速度为零；截断片段边界保留原始速度。摆动高度在支撑切换附近渐入渐出。减少滑动，但膝关节速度增大。
- `smooth_v4`：进一步把人体踝的相对离地高度映射到机器人脚底；机器人踝绝对高度按自身碰撞球偏移计算，避免原始踝目标与脚底高度残差相互冲突。
- 当前候选额外将根部高度降低 6 cm、摆动离地高度乘以 0.6。这两个值是可复现实验参数；根部 XY、旋转及时间轴不改变，不能再声称根部完整轨迹与旧版相同。

直接低通滤波降低了关节速度，却增大支撑脚滑动；逐帧硬限速为 6 rad/s 会使跟踪滞后，支撑覆盖降至约 59%–71%。两者均未加入当前候选预设。工具仍保留以便复现实验，不作为默认后处理。

## 复现

```bash
python scripts/prepare_cmu_dataset.py --config configs/cmu_walk_candidate.json --output data/processed/cmu_walk_candidate_v1
python scripts/audit_dataset.py data/processed/cmu_walk_candidate_v1/manifest.json --output outputs/candidate_contact_audit.json
python scripts/smoke_cpu.py --motions data/processed/cmu_walk_candidate_v1/train/*/candidate_amp.npz --output outputs/candidate_smoke
```

`configs/cmu_walk_candidate.json` 是候选配置，不会改变不带 `--config` 的基础 IK。显式命令行参数覆盖预设，配置与来源哈希写入 manifest。验证集不会被上述 smoke 的 train glob 选入。

`--floor-ik-variant anchor_v2` 可复现上版，`smooth_v3` 保留中间对比。低通实验：

```bash
amp-lab motion smooth input_qpos.npz --output filtered_qpos.npz --sigma-seconds 0.04
amp-lab motion convert filtered_qpos.npz --output filtered_amp.npz
amp-lab motion audit filtered_amp.npz
```

滤波需要匹配源数据的 `.retarget.json`，输出保留父级来源和哈希，清除已有动力学验证标记。它是离线、非因果处理，保留根部数组；重新计算 FK 与审计是必需步骤。

## 本地证据

- `data/processed/cmu_walk_candidate_v1/manifest.json`：可复现候选；与旧名称 `cmu_walk_floor_ik_v4_compact` 的四段 AMP 文件哈希完全一致。
- `outputs/cmu_smoothing_train_sweep.json`、`outputs/cmu_v4_smoothing_train_sweep.json`：滤波对比，仅训练片段。
- `outputs/cpu_smoke_v3/report.json`：三段候选数据的 3 次更新/恢复/导出/推理，明确诊断用途；不是学习曲线或行走能力证明。
- `outputs/cmu07_01_floor_ik_v4_reference.mp4`：参考数据回放，不是策略动作。
