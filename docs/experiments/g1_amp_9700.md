# G1 平地 AMP 示例候选：seed42 / iteration9700

已在真实 Isaac Sim 4.5.0 / IsaacLab v2.1.0 与原生 MuJoCo 3.3.7 完成同一 ONNX 的平地速度指令测试。
本地 CPU MuJoCo 重现远端结果。候选尚未公开发布；上游条款和分发材料仍需整理，未提供下载链接。

## 策略与训练

- 机器人：Unitree G1 29DoF；实际训练 URDF、部署 MJCF 与 mesh 来自锁定的 assetslib。
- 算法：beyondAMP AMPPPO、ActorCritic、AMPDiscriminator；由 seed42 随机初始化训练，未使用上游预训练策略。
- 配置：`configs/train_g1_rsi_speed.json`；4096环境，每次24控制步；80%参考状态初始化、20%默认起步。
- checkpoint：第9700次更新，953,548,800 transitions；保存了策略、判别器、优化器、replay与RNG。
- actor输入96维，动作29维，50Hz控制，200Hz物理和显式PD；部署契约来自实际训练环境，按关节名对齐。
- AMP使用关节位置、0.05倍关节速度与根部机体系线速度，单帧61维。
- 此候选使用原始 `cmu_walk_candidate_v1`，没有使用后续65%时间速度实验数据。

训练从200次完整checkpoint恢复到1000次，再从1000次接续长程至20000次；候选固定选择9700次，后续训练不改写它。
环境状态在恢复时重置，不声称轨迹连续或位级复现。

## 独立直行测试

指令 `[0.6,0,0]`，持续20秒，两边均完成且未跌倒。

| 指标 | MuJoCo | Isaac |
| --- | ---: | ---: |
| 平均前进速度 m/s | 0.588079 | 0.601111 |
| XY速度RMSE m/s | 0.020916 | 0.018256 |
| 偏航角速度RMSE rad/s | 0.121386 | 0.117710 |

这通过首版平地行走门槛。早期400次策略虽然也能20秒不倒，但偏航RMSE约1.13rad/s，不能作为直行示例。
发布检查已加入偏航RMSE上限0.3rad/s，防止平均角速度接近零掩盖大幅左右摆动。

## 指令和朝向矩阵

两个模拟器各24项：8种指令 × 初始朝向0/+90/-90度。每项20秒，全部未跌倒。

- 站立 `[0,0,0]`。
- 前进 `[0.3,0,0]`、`[0.6,0,0]`、`[0.9,0,0]`。
- 侧向 `[0.6,+0.1,0]`、`[0.6,-0.1,0]`。
- 转向 `[0.6,0,+0.3]`、`[0.6,0,-0.3]`。

MuJoCo逐项运行；Isaac使用24个平行环境，统一数据/控制契约、各自独立默认起步。
矩阵最大速度/偏航RMSE：MuJoCo为0.048601m/s / 0.166344rad/s，Isaac为0.040525m/s / 0.146882rad/s。

单进程Isaac直行另行执行，并录制完整20秒视频，结果与无渲染单环境一致。
这些是固定矩阵开发评测，不是随机多seed、复杂地形、外力扰动或真机测试。
