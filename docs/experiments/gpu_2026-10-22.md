# 首次真实 GPU 实验：2026-10-22

目标是验证 beyondAMP 自定义训练到部署链路，随后做一轮有界 pilot。小规模更新和推理成功不代表学会行走。

## 环境与来源

用户创建的 gradmotion RTX 4090 D（24GB），Ubuntu 22.04.5，驱动 535.154.05，Python 3.10.15，Isaac Sim 4.5.0 / Lab v2.1.0（扩展 0.36.21）。Isaac 启动后 torch 为其 prebundle 的 2.5.1+cu118；普通 Python 为镜像原有 2.5.1+cu124，未覆盖镜像 torch。

Lab source/apps 与固定提交 `21f7136325136ca3f6ca4e0a8125edffe5c24f7e` 对照 807 个文件。唯一平台差异是 `utils/assets.py` 将 Nucleus 资源根目录设为 `/root/Assets/Isaac/4.5`。保留并声明该补丁；项目 G1 使用独立锁定的 URDF/mesh。三份上游依赖仍按 `configs/upstream.lock.json` 的 SHA 获取。

运行目录 `/root/amp-lab`，日志 `/root/amp-runlogs`。候选数据 `cmu_walk_candidate_v1`：训练 07_01/02/03，开发验证 07_06，沿用数据清单与指纹；同人验证不能作为跨人泛化证据。

## 已发现并修复的问题

- Isaac `get_version()` 返回 `(完整版本, prerelease, major, minor, patch, ...)`，原校验错误拼接前三项。已改读第一个字段，并用实际返回格式建立回归检查。
- GPU 安装需保留 IsaacLab 要求的 ONNX 1.16.1，新增 `constraints/isaac45.txt`。CPU 约束中的 ONNX 1.17.0 不应套用到现成 Isaac 镜像。
- 首次 URDF 转换触发在线下载缺少的 Isaac 扩展。后续同机运行复用缓存；部署指南不能宣称该镜像首次训练不需要联网。
