# G1 AMP seed43 6000 次候选

这是 v0.1.0 公开示例，来自 beyondAMP 训练流程。使用固定专家统计的 AMP 标准化、yaw 奖励权重 1.0、4096 个并行环境和 seed 43，从头训练 6000 次；训练使用 CMU 07_01、07_02、07_03 重定向数据，数据来源与处理见 [数据说明](../data.md)。

同一 ONNX 在 MuJoCo 与 Isaac Sim 4.5.0 / IsaacLab 2.1.0 分别测试 24 个速度与初始朝向组合，每项 20 秒均未跌倒。最大平面速度 RMSE 分别为 0.05954 / 0.05807 m/s，最大偏航角速度 RMSE 为 0.12158 / 0.07242 rad/s。此测试覆盖平地，不代表复杂地形或真实机器人表现。

MuJoCo 直行 0.6 / 0.9 m/s 的双脚底高度 P95 均值分别为 7.088 / 8.287 cm；最低支撑脚水平速度代理分别为 0.01952 / 0.03838 m/s。支撑判定来自高度而非接触力，参考数据与策略速度并不完全一致，不能将这些指标换算成动作相似百分比。
